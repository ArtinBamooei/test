# Artin Bamooei — Academic & Technical Portfolio

A multilingual personal portfolio (English, Persian, German) built as a lightweight static website.

## Run locally
Open `index.html` in a browser.

## Publish with GitHub Pages
In the repository, open **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**, choose **main** and **/(root)**, then save.

The site uses plain HTML, CSS, and JavaScript. No build step or package installation is required.

## Content policy
Education, project status, and research interests are presented conservatively. Add verified contact details, certificates, skills, and experience only when confirmed.
